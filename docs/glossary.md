# Glossary

| Term | Plain-language meaning |
| --- | --- |
| Attrition | Participants dropping out of the data before the outcome is measured |
| Bandwidth | In RDD, how far from the cutoff students can be and still be compared |
| Causal effect | The difference between what happened with the program and what would have happened without it |
| Clustering | People grouped in units (students in schools) who share influences, so they aren't fully independent |
| Coefficient | In regression, how much the outcome changes per one-unit change in a predictor, holding others constant |
| Cohen's d | A difference expressed in standard deviation units |
| Comparison (control) group | People who did not get the program, used to estimate what would have happened |
| Conditional average treatment effect (CATE) | The average effect for people who share a characteristic, such as English learners |
| Confidence interval (CI) | A plausible range for the true value; 95% is the usual level |
| Confounder | A factor that affects both who gets the program and the outcome |
| Counterfactual | What would have happened without the program; never directly observed |
| Covariate | A variable measured before the program, included in an analysis to adjust for differences between groups or to make the estimate more precise. In JASP's regressions, the Covariates box holds every numeric predictor. |
| Dependent variable (outcome) | The variable an analysis tries to explain; in an evaluation, what the program is meant to change |
| Dose-response | How the outcome changes with the amount of a program received, such as the number of tutoring sessions |
| Effect size | How big a difference is, in units that can be compared (usually SD) |
| Effect heterogeneity | A program's effect being larger for some people than for others |
| External validity | Whether a result would hold for other people, places or years than the ones studied |
| Fixed effect | In a mixed model, an effect estimated as one value for everyone, such as the DiD estimate |
| Grouping variable | A categorical variable that sorts rows into the groups being compared, such as arise\_group in a t-test |
| Independent variable (predictor) | A variable used to explain the outcome. The treatment is the independent variable an evaluation is about; covariates are the others. |
| Interaction | A product of two predictors; its coefficient shows whether one predictor's effect depends on the other |
| Internal validity | How confident you can be that the program, not something else, caused the result |
| Intent-to-treat (ITT) | The effect of being offered or assigned a program, whether or not people took it |
| Moderator | A characteristic that changes the size of a program's effect; its interaction with the treatment measures how much |
| Odds ratio | In logistic regression, how the odds of an outcome change per one-unit change in a predictor |
| p-value | The probability of a result at least this large if the program truly had no effect |
| Parallel trends | The DiD assumption that both groups would have changed equally without the program |
| Propensity score | A person's predicted probability of being in the program group |
| R² | The share of the outcome's variation a model explains |
| Random effect | In a mixed model, a value allowed to differ across clusters (such as each school's baseline); the model estimates how much it varies |
| Running variable | In RDD, the score that decides eligibility |
| Selection bias | A difference caused by who chose (or was chosen) to be in the program, not by the program |
| Standard error (SE) | How much an estimate would vary from sample to sample; smaller = more precise |
| z-score | A score expressed as standard deviations above or below a reference average |
